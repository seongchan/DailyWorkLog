# Daily Work Log

일일 마크다운 노트에서 작업 시간 기록(이벤트)과 할 일 목록을 바로 시각화해주는 옵시디언 플러그인입니다. YAML frontmatter가 필요 없습니다.

*[English README is here.](./README.md)*

## 주요 기능

- **그리드 타임라인**: 사이드바에 10분 단위 셀 그리드 — 드래그로 새 시간 블록을 기록하고, 기존 블록을 클릭해 수정합니다.
- **카테고리**: 색상으로 구분되는 카테고리(기본 5종 — Work/Study/Rest/Reading/Exercise — 및 사용자 정의 최대 10개), 본문에 `[카테고리]` 태그 형태로 그대로 저장됩니다.
- **접이식 할 일 패널**: 사이드바 하단에 고정, 인라인으로 추가/체크/삭제.
- **PDF / HTML 내보내기**: 하루치 기록을 인쇄 가능한 standalone HTML 파일로 내보냅니다.
- **일일노트 저장 폴더 설정**: 노트를 볼트 루트가 아닌 다른 폴더에도 저장할 수 있고, 설정에서 폴더 자동완성을 지원합니다.
- **최소한의 메타데이터**: 별도의 frontmatter 없이, 마크다운 본문의 헤더 3개만으로 동작합니다.
- **다국어 + 하위호환 마커 인식**: 노트에 `Event` / `ToDo` / `Diary`(또는 한국어 `이벤트` / `할일` / `다이어리`) 헤더를 씁니다. 예전 언더스코어 표기(`_Event` 등)로 작성된 노트도 계속 인식되어 깨지지 않습니다.
- **UI 언어 자동 감지**: 최초 실행 시 Obsidian 자체 언어 설정을 기반으로 자동 감지되며, 설정에서 언제든 바꿀 수 있습니다.
- **서로 독립적인 두 가지 테마**: 사이드바 전용 라이트/다크 설정(Obsidian 전체 테마와 별개이며, 팝업은 항상 시스템 테마를 따름)과, Obsidian 테마를 그대로 따르는 일과 인사이트.
- **일과 인사이트**: 볼트 요약 및 통계 — 설정된 폴더 내 노트 수, 연속 작성일(스트릭), 조회 기간 필터(7일/30일/90일/전체), To-Do 달성률, 총 기록 시간 및 일평균 기록, 카테고리별 기록 시간 비중 시각화(Multi-Segment Progress Bar) 및 최근 일과 내역.

## 일일 노트 형식

일일 노트 파일명은 `YYYY-MM-DD.md` 형식이어야 합니다. 플러그인으로 새 노트를 생성하면 다음과 같은 형태로 만들어집니다.

```markdown
# Event

- 9:00 - 10:30 [Work] 팀 회의

# ToDo

- [x] 주간 보고서 제출
- [ ] PR 리뷰

# Diary

자유롭게 메모하는 공간입니다 — 사이드바에는 노출되지 않습니다.
```

- 시간 범위 뒤의 `[카테고리]` 태그는 선택사항입니다 — `- 9:00 - 10:30 팀 회의`(카테고리 없이)도 그대로 동작합니다.
- 세 블록은 어떤 순서로 있어도 상관없습니다.
- 이 형식이 도입되기 전(`# _Event`처럼 언더스코어가 붙은 형태)에 작성된 노트도 계속 인식됩니다 — 두 표기를 동시에 지원합니다.
- 세 헤더가 하나도 없는 파일은, 파일 어디에 있든 `- [ ]`/`- [x]` 줄은 할 일로, `- HH:mm - HH:mm ...` 줄은 이벤트로 인식하는 방식으로 대체 동작합니다.

## 설치 방법

아직 커뮤니티 플러그인 브라우저에는 등록되어 있지 않습니다. 수동 설치 방법은 다음과 같습니다.

1. [릴리스](../../releases)에서 `main.js`, `manifest.json`, `styles.css` 세 파일을 내려받습니다 (또는 아래처럼 직접 빌드).
2. 세 파일을 `<볼트 경로>/.obsidian/plugins/daily-work-log/`에 복사합니다.
3. 옵시디언에서 **설정 → Community plugins**로 이동해 (필요하면 Restricted mode를 끄고) **Daily Work Log**를 활성화합니다.

### 소스에서 직접 빌드하기

```bash
npm install
npm run build   # dist/main.js, dist/manifest.json, dist/styles.css 생성
```

개발 중에는 `npm run dev`를 사용하세요 — 코드가 바뀔 때마다 자동으로 다시 빌드됩니다 (esbuild watch 모드).

> #### **[!TIP]**  
>
> **DayTime Tracker에서 넘어오시나요?** 그 플러그인은 데이터를 본문이 아니라 `timeline-logs` / `timeline-todos`라는 YAML frontmatter 프로퍼티에 저장합니다. `scripts/migrate-from-daytimetracker.mjs`로 기존 일일 노트를 이 플러그인 형식으로 변환할 수 있습니다.
>
> 이 스크립트는 소스 저장소에만 있고 릴리스 다운로드에는 포함되어 있지 않습니다(릴리스에는 `main.js`/`manifest.json`/`styles.css`만 들어있음) — 먼저 이 저장소를 clone하고 `npm install`을 실행해야 합니다:
>
> ```bash
> git clone https://github.com/seongchan/DailyWorkLog.git
> cd DailyWorkLog
> npm install
> node scripts/migrate-from-daytimetracker.mjs <볼트 경로>            # 드라이런 — 아무것도 안 쓰고 미리보기만
> node scripts/migrate-from-daytimetracker.mjs <볼트 경로> --write    # 실제로 파일 수정
> ```
>
> 항상 드라이런을 먼저 돌려보고, `--write`를 쓰기 전에 볼트를 백업하세요 — 노트를 그 자리에서 덮어쓰며 되돌릴 방법이 없습니다. 정확히 무엇이 변환되고 무엇이 안 되는지는 스크립트 상단 주석을 참고하세요.

## 사용 방법

### 사이드바에서

- **일과 인사이트 열기**: 리본 아이콘(gauge)을 클릭하거나, 커맨드 팔레트에서 **"일과 인사이트 열기"**를 실행하세요. 메인 워크스페이스의 일반 탭으로 열립니다.

- **사이드바 열기**: 리본 아이콘(calendar-clock)을 클릭하거나, 커맨드 팔레트(`Cmd/Ctrl+P`)에서 **"사이드바 열기"**를 실행하세요. **설정 → 단축키**에서 원하는 단축키를 지정할 수도 있습니다.
- 그리드를 드래그하면 새 시간 블록이 기록되고, 기존 블록을 클릭하면 수정/삭제할 수 있습니다.
- 사이드바 상단의 **오늘** 버튼으로 오늘 노트를 열거나 생성하고, **인쇄** 버튼으로 현재 날짜를 인쇄용 HTML로 내보낼 수 있습니다.

### 노트에 직접 입력하기

사이드바가 꼭 필요한 건 아닙니다 — 사이드바는 그냥 평범한 마크다운 위에 얹힌 UI일 뿐이라, 노트에 직접 타이핑해도 완전히 동일하게 동작합니다. 각 헤더 아래에 다음 형식으로 줄을 추가하면 됩니다.

```markdown
# Event

- 9:00 - 10:30 [Work] 팀 회의
- 14:00 - 14:30 카테고리 없는 짧은 통화

# ToDo

- [ ] 할 일
- [x] 완료한 일
```

- 이벤트: `- HH:mm - HH:mm [카테고리] 설명` 형식. `[카테고리]` 부분은 선택사항이며, **설정 → 카테고리 설정**에 등록된 카테고리 이름과 일치해야 색상이 반영됩니다 (없거나 일치하지 않으면 미분류로 표시됨).
- 할 일: `- [ ] 텍스트` / `- [x] 텍스트` — 일반 Obsidian 체크박스와 동일합니다.
- 파일을 저장하면(또는 그냥 계속 타이핑만 해도 Obsidian이 자동 저장하므로) 사이드바/대시보드에 즉시 반영됩니다.

#### 여러 줄 메모 작성하기

이벤트나 할 일 줄 바로 다음에 오는 줄이, 그 자체로 새로운 이벤트/할 일/헤더처럼 보이지만 않는다면 바로 위 항목에 딸린 부가 메모로 인식됩니다 — 한 줄짜리 설명에 다 담기 애매한 상세 내용을 적을 때 유용합니다.

```markdown
# Event

- 9:00 - 10:30 [Work] 팀 회의
3분기 로드맵 논의 및 디자인팀과 후속 일정 확정.
다음 주 후속 회의 예정.

# ToDo

- [ ] 릴리스 배포
롤백 절차는 운영 매뉴얼에 정리되어 있음.
```

- **이벤트**는 사이드바에서 바로 지원됩니다 — 추가/수정 팝업의 설명 입력창에서 Enter를 눌러 여러 줄을 입력하면 그대로 저장되고, 다시 열었을 때도 전체 내용이 보입니다.
- **할 일**은 사이드바의 빠른 추가 입력창이 아직 한 줄짜리라 UI로는 못 넣지만, 노트 형식 자체는 지원합니다 — `- [ ]`/`- [x]` 줄 바로 다음에 노트에 직접 줄을 추가하면 됩니다. 사이드바가 아직 보여주거나 편집하진 못해도 내용은 보존되며, 할 일을 삭제하면 딸린 메모도 함께 삭제됩니다.
- 메모 줄 자체가 새로운 시간 범위(`09:00 - 10:00 ...`)나 체크박스(`- [ ] ...`)처럼 시작할 수는 없습니다 — 그렇게 두면 다음에 노트를 다시 읽을 때 별개의 새 항목으로 잘못 인식됩니다. 사이드바에서는 이렇게 저장하려 하면 막아주며, 노트를 직접 편집할 때는 그런 식으로 줄을 시작하지 않으면 됩니다.
- 빈 줄 1개는 문단 구분으로 그대로 유지되지만, **빈 줄이 2개 이상 연속되면 그 지점부터는 더 이상 이 항목에 포함되지 않습니다** — 삭제되는 건 아니고 노트 파일에는 그대로 남아있지만, 사이드바에서는 더 이상 보이지 않고 해당 항목을 수정해도 건드리지 않습니다. 사이드바에서 저장할 때는 개행이 3개 이상 연속되면 자동으로 빈 줄 1개로 정리됩니다.

#### HTML 태그 사용 시 주의사항

이벤트, 할일에 입력한 내용을 사이드뷰에서 볼 때에는 HTML 태그를 제외해서 처리합니다. 단순한 태그 패턴(`<...>`) 매칭을 사용하므로, 설명에 실제 부등호 비교(예: `3 < 5`, `10 > 2`)를 텍스트로 적으면 태그로 오인되어 사이드바/내보내기에서 사라질 수 있습니다. 부등호를 텍스트로 표현해야 한다면 `&lt;`, `&gt;` 같은 HTML 엔티티를 사용하거나 다른 표현으로 대체하세요.

## 설정

- **하루 시작 시간 / 하루 종료 시간**: 그리드에 표시할 시간 범위.
- **날짜 노트 생성 폴더**: 새 일일 노트가 생성될 위치(기본값은 볼트 루트), 폴더 자동완성 지원.
- **언어**: 최초 실행 시 Obsidian 자체 UI 언어를 기반으로 자동 감지됩니다. 새 노트에 삽입되는 마커 라벨과 사이드바/설정 화면의 모든 문구를 결정하며, 이 설정과 무관하게 어느 언어로 작성된 기존 노트든 계속 정상적으로 인식됩니다.
- **배경 테마 설정**: 사이드바에만 적용되는 라이트/다크 설정입니다.
- **카테고리 설정**: 카테고리 추가/이름 변경/색상 변경/삭제, 또는 기본값으로 재설정.
